# Backend contracts / Контракты сервера

**Status / Статус: BLOCKED.** Owner / Ответственный: backend.

Required: desktop browser return and token exchange, account-session lifecycle, account balance/spending API and HTTPS top-up navigation. Observed public responses are distinguished from proposals. No proposed contract is presented as an existing API.

Требуются возврат из браузера и обмен кода на токены, жизненный цикл сессии аккаунта, API баланса и расходов, а также HTTPS-переход к пополнению. Наблюдавшиеся публичные ответы отделены от предложений. Ни один предложенный контракт не выдаётся за действующий API.

需要确认桌面端浏览器回调和令牌交换、账号会话生命周期、余额与支出接口，以及 HTTPS 充值跳转。实际观察和建议方案分开记录；建议不代表已有 API。
